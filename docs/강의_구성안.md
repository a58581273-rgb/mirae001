## 슬라이드에 들어갈 프롬프트 예문 (복사해서 바로 쓰는 용)

```text
1부터 100 사이 숫자 맞추기 게임을 HTML 파일 하나로 만들어줘.
UP/DOWN 힌트와 시도 횟수를 보여주고, 글씨는 크게 해줘.
```

```text
가위바위보 게임을 HTML 파일 하나로 만들어줘.
이모지 버튼 3개, 승/무/패 점수판, 밝고 귀여운 디자인으로.
```

```text
요리 재료 이모지로 4x4 카드 짝 맞추기 게임을 HTML 파일 하나로 만들어줘.
타이머와 클리어 메시지를 넣고, 글씨와 카드를 크게 해줘.
```

```text
30초 동안 두더지 잡기 게임을 HTML 파일 하나로 만들어줘.
점수, 남은 시간, 최고 기록 저장 기능을 넣어줘.
```

```text
방향키로 로켓을 움직여 떨어지는 별똥별을 피하는 게임을 HTML 파일 하나로 만들어줘.
시간이 지날수록 빨라지고, 버틴 시간과 최고 기록을 보여줘.
```

## 강의 대본 방향 (슬라이드 노트에 들어갈 내용 요약)

- **4번 (개념):** "챗GPT에 게임 만들어 달라고 하면 코드를 '보여'줍니다. 그걸 복사해서 저장하는 건 우리 몫이죠. 에이전트는 파일을 직접 만들고, 열어 보고, 안 되면 스스로 고칩니다."
- **6번 (시연):** 5개 게임을 쉬운 순서로 실제 플레이. 마지막 별똥별 피하기에서 수강생 1명을 불러 최고 기록 도전.
- **8번 (고치기):** 일부러 "글자를 더 크게" 같은 쉬운 요청부터. "코드를 한 줄도 안 봤다"는 점을 강조.
- **11번 (실습):** 진도가 빠른 분은 두더지 잡기에 "두더지 대신 고양이로" 같은 추가 과제.
